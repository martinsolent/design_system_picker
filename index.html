    Things to know before you use a system
    
    
    
      
    Previews are approximations
    Each preview is drawn from a system's colours, type and shapes. It does not load the real component library, so the real thing will differ in detail.
    
      
    Token values are a starting point
    Colours, fonts and corner sizes were written from memory, not copied from each project. Confirm them in the official docs before you rely on them.
    
      
    Starter previews are simpler
    Where a system is marked as a starter preview, only its main colour, font and corner shapes are specific to it. The greys and spacing are generic.
    
      
    Some systems have no preview
    Systems without stored colours show a plain wireframe. You still get the licence, the links and a prompt to copy.
    
      
    Licences were checked once
    Each licence was read from the project's own repository on 17 November 2026. Licences can change, so read the current one before you publish or sell anything built with a system.
    
      
    Some licences have sharing conditions
    MIT, Apache, BSD and CC0 let you use the code freely. GPL, LGPL, EUPL and MPL ask you to share your changes under the same terms in some situations.
    
      
    A few licences rest on weaker evidence
    Where an entry says "declared in package.json", the project has no separate licence file. Treat those with more care.
    
      
    Not every project is still maintained
    Maintenance was not checked. Open the source code link and look for recent activity before you commit to a system.
    
      
    A licence covers the code, not the brand
    Names, logos and some fonts stay protected. Never present a prototype in a government, health service or company style as if it were the real service.
